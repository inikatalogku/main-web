Selamat Datang di Tutorial IniKatalogku

Panduan lengkap untuk menguasai Backoffice IniKatalogku. Mulai dari membuat akun, login, mengelola produk, hingga memproses pesanan pelanggan Anda. Ikuti langkah-langkah di bawah ini dengan teliti.

Estimasi Baca: 10 Menit

1. Registrasi Akun Baru

Jika Anda belum memiliki akun, Anda perlu melakukan registrasi terlebih dahulu. Klik tombol "Buat Akun Baru" di halaman login.

1

Isi Data Diri

Masukkan Email aktif, Nama Lengkap, Username yang diinginkan, dan Password. Pastikan password mudah diingat namun sulit ditebak.

2

Verifikasi Nomor HP

Masukkan Nomor HP yang sudah terdaftar di sistem IniKatalogku. Sistem akan menolak pendaftaran jika nomor HP belum terdaftar.

Pastikan format nomor HP diawali dengan "08...".
3

Klik "Daftar Akun"

Jika semua data valid dan nomor HP terdaftar, Anda akan mendapat notifikasi "Registrasi berhasil" dan otomatis diarahkan ke halaman Login.

2. Login & Ganti Password Sementara

Jika Anda sudah memiliki akun, masukkan Username dan Password di halaman utama, lalu klik "Masuk".

Kondisi Password Sementara

Jika Anda login menggunakan password sementara (lupa password), Anda akan dipaksa masuk ke halaman "Ganti Password". Anda harus membuat password baru (minimal 6 karakter) sebelum dapat mengakses Dashboard.

1

Masuk ke Dashboard

Setelah berhasil login, klik tombol "Klik untuk melanjutkan" di Welcome Screen untuk masuk ke Dashboard utama.

3. Lupa Password

Jika Anda lupa password, gunakan fitur "Lupa Password" di bawah form login.

1

Pilih Mode Pencarian

Anda bisa mencari akun berdasarkan Username atau Email. Klik tombol "Cari Berdasarkan..." untuk berganti mode.

2

Kirim Password Sementara

Masukkan Username/Email Anda, lalu klik "Kirim Password Sementara". Sistem akan mengirim email berisi password acak ke email Anda.

3

Login dengan Password Baru

Buka email Anda, catat password sementara tersebut, lalu login dengan password tersebut. Anda akan otomatis diminta membuat password baru permanen (Lihat bagian Login di atas).

4. Dashboard & Status Trial

Di Dashboard, Anda akan melihat statistik stok, tombol aksi cepat, dan tabel produk.

Sistem Masa Trial

Di bagian atas dashboard, terdapat banner Trial. Banner ini menginformasikan sisa hari masa trial Anda. Jika masa trial habis, Anda tidak bisa mengakses backoffice namun halaman katalog pelanggan tetap aktif selama 14 hari ke depan. Klik "Info" untuk melihat detail tanggal mulai dan berakhir.

Widget Statistik Stok

Di dashboard terdapat 3 kotak statistik berwarna yang menampilkan status stok toko Anda:

Produk Habis

Klik untuk melihat produk dengan stok 0.

Stok Rendah

Klik untuk melihat produk yang stoknya hampir habis (batas dapat diatur di Pengaturan).

Stok Aman

Klik untuk melihat produk dengan stok melimpah.

5. Manajemen Produk

Klik tombol "+ Tambah" untuk menambahkan produk baru.

1

Isi Detail Produk

Isi Judul, Kategori (bisa diketik manual atau pilih dari daftar), Harga, Stok, Berat (gram), dan Deskripsi produk. Anda juga bisa mencentang Best Seller untuk menandai produk unggulan.

2

Upload Foto & Cropping

Klik area upload untuk memilih foto. Setelah dipilih, Anda akan masuk ke mode Crop. Geser gambar untuk menyesuaikan posisi, cubit (pinch) atau gunakan tombol Zoom untuk mengatur ukuran. Klik "Terapkan" untuk mengupload.

Tips: Upload minimal 1 foto. Gunakan rasio kotak (1:1) agar hasil terbaik di katalog pelanggan.
3

Simpan Produk

Tunggu hingga proses upload foto selesai (ikon loading hilang). Kemudian klik "Simpan Produk". Produk akan langsung masuk ke daftar tabel.

4

Edit & Hapus Produk

Di tabel produk, klik ikon Pencil untuk mengubah data, atau ikon Tong sampah untuk menghapus produk. Konfirmasi penghapusan akan muncul.

6. Pengaturan Toko

Akses melalui ikon Avatar (pojok kanan atas) -> Pengaturan Toko. Atur identitas toko Anda agar tampil menarik di halaman pelanggan.

  • Identitas: Nama Toko, Tagline, dan Upload Logo.
  • Kontak: Isi Nomor WhatsApp Admin (format 628...) untuk menerima pesanan otomatis.
  • Form Pesanan: Centang bagian "Tampil" agar field muncul di halaman pelanggan, dan centang "Wajib" agar field tersebut wajib diisi oleh pembeli sebelum checkout.
  • Notifikasi Stok: Atur batas minimal stok (misal 5). Jika stok turun di bawah batas, Anda akan mendapat peringatan lonceng di dashboard.
  • Tema Warna: Pilih warna tema katalog Anda (Gold, Blue, Green, Pink, atau Purple).

Jangan lupa klik "Simpan Pengaturan" di bagian bawah.

7. Manajemen Order

Klik tombol "Order" untuk melihat daftar pesanan yang masuk dari pelanggan.

1

Filter & Pencarian

Gunakan kotak statistik (New, Pending, Proses, Batal) untuk memfilter status pesanan. Gunakan search bar untuk mencari berdasarkan Nama, WA, atau Order ID.

2

Update Status

Klik badge Status (misal: New Order/Pending) pada baris pesanan untuk mengubahnya menjadi "Diproses" atau "Batal". Anda juga bisa centang beberapa order sekaligus dan gunakan menu Batch Update untuk mengubah status massal.

3

Lihat Detail & Chat WA

Klik ikon Mata () untuk melihat rincian pesanan. Di dalamnya, ada tombol "Chat WhatsApp" yang akan otomatis membuka WA dengan teast pesan template.

4

Export Data

Klik tombol "Export Excel" untuk mengunduh seluruh data order ke dalam format .XLSX.

8. Bagikan Katalog

Klik tombol "Share" untuk mendapatkan link toko Anda.

  • Salin Link: Copy link katalog, lalu paste ke sosial media atau WA pelanggan Anda.
  • Bagikan Native: Gunakan fitur share bawaan HP/Chrome Anda untuk langsung share ke WA/IG.
  • Buka Katalog: Buka pratinjau katalog Anda di tab baru untuk memastikan tampilannya sudah sesuai.
